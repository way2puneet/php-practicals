PHP Practicals

All 25 practicals of Paper CSA-DSC-6(Maj)-602P. Each one has the complete code, real screenshots of its output, a simple explanation, and a Run button that runs real PHP right in this page.

1. Read the aimWhat the program does, and the test data.
2. Read the codeThen compare with the real output.
3. Understand itHow it works, in the book’s words.
4. Run it hereFill the form, click links, change the code.
No installation needed to start. Twenty-one practicals run inside your browser. The four database practicals (16, 17, 18 and 23) need MySQL: see Setup to run everything in XAMPP.
