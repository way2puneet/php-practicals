Before you start

Setup

Do this once. After that, every practical is: save the file in its folder, and open it in the browser through localhost.

1. Install XAMPP

  1. Download XAMPP for Windows from apachefriends.org and install it in C:\xampp.
  2. Open the XAMPP Control Panel and click Start next to Apache. For the database practicals, also start MySQL.
  3. Open http://localhost in the browser. The XAMPP welcome page means Apache is working.

2. Where to save the programs

PHP files must be opened through the web server, not by double-clicking them. Save every program inside C:\xampp\htdocs. The book uses one folder per chapter:

C:\xampp\htdocs\phpbook\ch02\details.php              → open http://localhost/phpbook/ch02/details.php

Each practical page shows the exact folder and address under Running it in XAMPP. Use a plain-text editor such as Visual Studio Code or Notepad++, and save files with the .php extension.

3. Create the database (for Practicals 16, 17, 18 and 23)

The database practicals use the database college_db with a table students. Create it with the book’s own Programs 8.2 and 8.3:

  1. Start MySQL in the XAMPP Control Panel.
  2. Save the three files below in C:\xampp\htdocs\phpbook\ch08.
  3. Open http://localhost/phpbook/ch08/create-db.php, then http://localhost/phpbook/ch08/create-table.php.

If something goes wrong

ProblemWhat to do
The browser shows the PHP code instead of running itThe file was opened directly (the address starts with file:///). Open it through http://localhost/....
Apache does not start (port 80 in use)Another program, often Skype or IIS, is using port 80. Close it, or change Apache’s port in XAMPP’s Config.
Warning: include(...): Failed to open streamThe path to the included file is wrong. Check the folder name, for example includes/header.php.
Warning: Undefined array key "name"The result page was opened directly. Open the form page first and submit it.
Cannot modify header information - headers already sentsetcookie(), header() or session_start() came after some output. Move it to the top, before any HTML or spaces.
Unknown database 'college_db' / Access denied for user 'root'Start MySQL, run create-db.php and create-table.php, and use user root with an empty password.
