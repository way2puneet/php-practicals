Program 10.7: Handling a Database-Connection Exception Using try-catch

Book: Program 10.7 (Chapter 10)Needs MySQL (college_db)
AimTo write a PHP program that handles a database-connection exception with try-catch, showing a student-friendly message and recording the technical details privately.
ConceptsCodeOutputHow it worksRun itIn XAMPPCommon mistakesViva

Concepts used

mysqli_report() with exception reporting, mysqli_connect() inside try, mysqli_sql_exception, getCode(), getMessage(), error_log(), finally for cleanup.

Test data: First test: database college_db, containing a students table with four sample student records. Second test: database name changed to college, which does not exist.

Logic

  1. Enable MySQLi exception reporting and set $conn to null.
  2. Inside try, connect to the database and count the student records.
  3. In catch, record the technical error with error_log() and prepare a simple message.
  4. In finally, close the connection if it was opened.
  5. Display the message.

Code

<?phpmysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);   // throw exceptions $database = "college_db";$conn = null;$message = "";try {$conn = mysqli_connect("localhost", "root", "", $database);$result = mysqli_query($conn, "SELECT COUNT(*) AS total FROM students");$row = mysqli_fetch_assoc($result);$message = "Database connection established. Students registered: " . $row["total"];} catch (mysqli_sql_exception $e) {    // Technical details for the developer only    error_log("Database error " . $e->getCode() . ": " . $e->getMessage()); // Simple message for the user$message = "Database connection could not be established. Please try again later.";} finally {    if ($conn)     {        mysqli_close($conn);           // cleanup when the connection was opened    }}?><!DOCTYPE html><html lang="en"><head>    <meta charset="UTF-8">    <title>Database Connection Exception</title></head><body>    <h2>Student Database</h2>    <p><?php echo htmlspecialchars($message); ?></p></body></html>

Output

These are real screenshots, taken by running the program with the test data.

Understanding the output

The first output shows a normal connection; the count depends on the records present in the table, so it is a sample value. The second output shows that the failure was caught and that the user saw only a polite message, with no database name, account name, folder path or PHP warning. The log entry shows that the technical details were not lost but were recorded where only the developer can read them. If the MySQL service is stopped instead, the same polite message appears, while the log records a different code and message.

How it works

Successful connection: mysqli_report() makes every MySQLi error throw a mysqli_sql_exception. With the correct database name, mysqli_connect() succeeds, the query counts the records, and the message reports the count. The catch block is skipped, and the finally block closes the connection.

Failed connection: With the database name college, mysqli_connect() throws a mysqli_sql_exception with the code 1049 and the message Unknown database 'college'. The remaining statements of the try block are skipped, and the catch block writes the code and message to PHP's error log and prepares the polite message. In the finally block, $conn is still null, because the assignment did not take place, so no attempt is made to close a connection. No PHP warning appears in the page, because MySQLi reported the failure through the exception.

Run it yourself

This program needs MySQL. A MySQL database cannot run inside a web page, so there is no Run button here. Run it in XAMPP as shown below. The outputs above were produced by running this exact code against the college_db database (see Setup).

Running it in XAMPP

Start Apache and MySQL. Make sure that the database college_db and the students table have been created and contain sample records. Save the file in C:\xampp\htdocs\phpbook\ch10 and open http://localhost/phpbook/ch10/db-exception.php. Then change $database to "college", save, reload the page, and restore "college_db". In XAMPP, the error log entries can be read through the Logs button of the Apache row in the Control Panel.

Common mistakes

  • Omitting mysqli_report() on an older PHP version, where mysqli_connect() then returns false with a warning instead of throwing an exception.
  • Writing catch (Exception $e) and displaying $e->getMessage() to the user, which reveals the database details.
  • Calling mysqli_close($conn) in finally without checking that the connection was opened.
  • Displaying the connection details, such as the username or password, for checking purposes.

Viva questions

What does mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT) do?
It makes mysqli functions throw a mysqli_sql_exception on error, instead of returning false.
Why is the technical error message not shown to the user?
It can reveal database names, user names or file paths. It is written to the error log for the developer instead.
Which function writes a message to the error log?
error_log().
