Write a PHP code to create and throw a user-defined exception class.

Program 10.5: Creating and Throwing a User-Defined Exception Class

Book: Program 10.5 (Chapter 10)Runs in this page
AimTo write a PHP program that creates a user-defined exception class and throws and catches an exception of that class.
ConceptsCodeOutputHow it worksRun itIn XAMPPCommon mistakesViva

Concepts used

class, extends Exception, throw new, catch with a custom class, getMessage().

Test data: Marks 78, 120 and -5; the allowed range is 0 to 100.

Logic

  1. Define the class MarksException by extending Exception.
  2. Define checkMarks($marks), which throws a MarksException if the marks are outside 0 to 100, and otherwise returns a message that the marks are valid.
  3. Call the function for each value inside a try block, and catch MarksException in the catch block.

Code

<?php// User-defined exception class for invalid marksclass MarksException extends Exception{} // Throws MarksException when the marks are outside the allowed rangefunction checkMarks($marks){    if ($marks < 0 || $marks > 100) {        throw new MarksException("Marks must be between 0 and 100.");    }    return "Marks $marks accepted.";}?><!DOCTYPE html><html lang="en"><head>    <meta charset="UTF-8">    <title>User-Defined Exception</title></head><body>    <?php    foreach ([78, 120, -5] as $marks) {        try {            echo checkMarks($marks) . "<br>";        } catch (MarksException $e) {            echo "MarksException caught: " . $e->getMessage()                . " (value entered: $marks)<br>";        }    }    ?></body></html>

Output

These are real screenshots, taken by running the program with the test data.

Understanding the output

The value 78 lies within the range and was accepted. The values 120 and -5 lie outside it, so the function threw the user-defined exception, which was recognised by its own class name in the catch block. Because the class is derived from Exception, the same exceptions would also be caught by a block naming Exception, but naming MarksException makes the purpose of the block clear.

How it works

Defining the class: The statement class MarksException extends Exception creates a new exception class with an empty body. The class receives all the methods of Exception, so its objects carry a message and provide getMessage().

Throwing and catching: The function checkMarks() throws a new MarksException with the message "Marks must be between 0 and 100." when the value is outside the range. For 78, the function returns its acceptance message, which is displayed. For 120 and -5, the exception is thrown, the function ends, and the catch (MarksException $e) block, which names exactly this class, displays the message together with the value entered.

Common mistakes
  • Writing the class without extends Exception, so that its objects cannot be thrown.
  • Throwing the custom exception before the class has been defined in the program.
  • Misspelling the class name in the catch block, so that the block does not match and the exception remains uncaught.


Viva questions
How is a user-defined exception created?
By writing a class that extends Exception, for example class MarksException extends Exception {}.
Why create your own exception class?
So that a particular problem can be recognised by its class name and handled separately.
What do the keywords throw and catch do?
throw raises an exception object; catch receives an exception of the given class and handles it.
